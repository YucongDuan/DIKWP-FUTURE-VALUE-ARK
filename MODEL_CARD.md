# Model Card — DIKWP FutureValue Ark OS 1.0.0

## Intended use

Offline educational decision support for broad asset-class resilience, emergency-liquidity planning and plural-scenario stress testing.

## Not intended for

Specific securities, market timing, automatic execution, leverage, tax/legal advice, credit underwriting, insurance suitability, pension/benefit decisions or guaranteed capital preservation.

## Model family

Rule-based constraints plus deterministic constructive random search. No machine-learning model, external LLM or live market feed is required.

## Inputs

User-declared broad asset amounts, living-cost constraints, profile, scenario-importance weights and editable return assumptions.

## Outputs

Current stress metrics, constrained target weights, near-optimal ranges, rebalancing deltas, next-contribution plan and warnings.

## Known risks

Scenario omission, false precision, incorrect user data, wrong local legal/insurance assumptions, model risk, implementation cost and user over-reliance.

## Mitigations

Prominent disclaimers; no specific instruments; no broker connection; no automatic action; an explicit correlation/custody-break scenario; editable assumptions; deterministic replay; target ranges rather than a single precise allocation.
