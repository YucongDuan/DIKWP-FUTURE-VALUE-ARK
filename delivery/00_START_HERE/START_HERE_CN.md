# 开始使用 DIKWP FutureValue Ark OS v1.0.0

## 无需安装

双击 `01_DIRECT_APP/DIKWP_FUTURE_VALUE_ARK_v1.0.0.html`。

该应用完全离线，不连接券商，不执行交易。先填写必要生活支出、储备月数和近期确定支出，再修改当前资产和情景假设，最后点击“分析并生成资产区间”。

## Python

```bash
python 02_SOURCE_AND_PACKAGES/DIKWP_FUTURE_VALUE_ARK_OS_v1.0.0.pyz demo --workspace .valueark-demo --reset
```

## 解释边界

- 情景数字不是预测。
- 权重不是发生概率。
- 声明情景财富底线不是现实保证下限。
- 不推荐具体证券、基金、银行或保险。
- 实施前核对费用、税务、托管、流动性、信用和存款保险。
