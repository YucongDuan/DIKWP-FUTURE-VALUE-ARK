# Changelog

## 1.0.0 — 2026-09-02

- First public-ready research alpha.
- Standalone offline HTML application.
- Eleven broad asset classes and nine editable future worlds.
- Emergency-liquidity floor and user-declared deposit-insurance capacity check.
- Preservation, balanced and guarded-growth constraint profiles.
- Deterministic constructive random-search optimizer.
- Near-optimal target ranges, rebalancing and next-contribution plans.
- JSON/CSV import and JSON/CSV/Markdown export.
- Python CLI, tests, static audit and bounded action-state check.
- No broker connection, automatic trade, leverage, short selling or specific-security recommendation.
